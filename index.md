**The script doesn't seem to work in-game.**

Make sure the script is running (check your system tray). Press the toggle hotkey again to confirm it's enabled. Also verify you're holding spacebar – the script only works when you hold the jump key.

**Windows SmartScreen shows a warning.**

Click "More info" and then "Run anyway." This is normal for unsigned scripts. The file is safe.

**I get an error about missing .NET or Visual C++.**

**The script works but my hops feel off.**

Try adjusting the `Jump Delay` value in the config file. Increase it slightly (e.g., from 0 to 5) and test again. Small tweaks can make a big difference.
